# Catch-up Cards

A get-to-know-you game for screen-sharing on Teams: This or That, Mystery Cards, Weather Check, a wrap-up summary and a bonus Car Park Escape puzzle. Nothing is saved or sent anywhere; answers stay in the open browser tab.

## Run locally

    npm install
    npm run dev

## Deploy

Pushing to `main` builds the site and publishes it with GitHub Actions.
After the first `npm install`, commit the generated `package-lock.json`, then you can switch the workflow to `npm ci` for faster, repeatable builds.

One-time setup: in the repo, go to **Settings → Pages** and set **Source** to **GitHub Actions**.
